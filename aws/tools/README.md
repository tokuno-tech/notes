# cloudtech-quiz-extractor

CloudTech（kws-cloud-tech.com）の問題演習ページから、Claudeに貼るための情報だけを
抜き出してクリップボードにコピーするブックマークレット。

ページ全体のHTMLを貼ると数万〜十数万トークンを消費するが、これを使えば1問あたり
数千文字（解説込み）に収まる。DVA/SAA/SOA/MLA/AIP など、CloudTechの問題集ページ
（LearnDash + wpProQuiz）であれば試験区分を問わず動く。

BenchPrep（AWS公式模試）用は別物 → [`../aip/tools/`](../aip/tools/)

## セットアップ（最初の1回だけ）

1. `cloudtech-quiz-extractor.bookmarklet.txt` の中身（`javascript:` で始まる1行）を全部コピーする。
2. ブラウザのブックマークバーで空欄を右クリック →「ページを追加」（Chrome）。
   Safariなら適当なページをブックマークしてから編集。
3. 名前: 任意（例: `問題を抽出`）、URL: 手順1の文字列を貼り付けて保存。

## 使い方

1. CloudTechの問題演習ページ（例: `/quizzes/dva-1001-1010/`）を開く。
2. ブックマークをクリックすると、右上に抽出パネルが出る。
3. ボタンを選ぶと、その場でクリップボードにコピーされる。
   - **表示中の1問** — いま画面に出ている設問だけ
   - **誤答した問題だけ** — 回答済みのうち間違えたものをまとめて
   - **回答済みすべて**
   - **このページの全問** — 未回答も含む（問題文と選択肢のみになる）
4. 「解説を含める」のチェックを外すと、問題文＋選択肢＋正誤だけの軽い出力になる。
5. コピーに失敗した場合はパネル内のテキストエリアから手動でコピーできる。

## 出力フォーマット

```
# CloudTech DVA-1001-1010
出典: https://kws-cloud-tech.com/quizzes/dva-1001-1010/

### DVA-1002 ［分野4-トラブルシューティングと最適化］ (複数選択) — 誤答
習熟度: 学習中(不正解)（直近1回: 0/1 正解）

(問題文)

【選択肢】番号は解説内の「正解N / 不正解N」と対応
1. ○ ←あなたの解答 ...
2. ○ ...
3. × ←あなたの解答 ...

あなたの解答: 1,3 / 正解: 1,2

【解説】
(判断軸の表はMarkdownテーブルに変換される)
| | | 追加コスト | ... |
|---|---|---|---|
...
```

- **選択肢の番号は画面の表示順ではなく解説内の番号**（CloudTechは表示順をシャッフルするため）。
  解説の「正解 1 / 不正解 2」とそのまま突き合わせられる。
- 解説内の図版画像・Vimeo動画・AI質問ボタン等は落とし、絵文字は文字として残す。

## 仕様メモ

- 正誤の判定は `label.ctqd-correct-answer` / `ctqd-selected`（回答状態の復元機能）を第一に見る。
  クラスが無い（＝未回答）場合は、ページ内の `aickData.originalChoices` から正解を補完する。
- 非表示（`display:none`）の設問は `innerText` が改行を失うため、画面外にクローンを置いて
  レンダリングさせてからテキスト化している。
- 選択肢の元番号は `li[data-pos]`（0始まり）+1。

## ソース更新時

```sh
./build.sh
```

`cloudtech-quiz-extractor.bookmarklet.txt` が再生成されるので、ブックマークのURL欄に上書きする。
ビルドはコメント除去と空白圧縮をするだけなので、**文字列や正規表現リテラルの中に連続空白や
生のU+00A0を書かないこと**（書いた場合は build.sh がエラーで止まる）。
